# Input Methods — 鼠标、键盘、触摸与混合设备

## 输入-行为矩阵

| 操作 | 鼠标/触控板 | 键盘 | 触摸 | 约束 |
|---|---|---|---|---|
| 主要按钮 | Click | Tab + Enter/Space | Tap | 语义一致 |
| 查看对象更多操作 | 点击菜单/右键辅助 | 菜单按钮获得焦点后触发 | 可见“更多”Tap，长按可辅助 | 不依赖右键/长按 |
| 选择多项 | Checkbox、Shift 可辅助 | 可聚焦选择控件 | 明显选择模式 | 不强制精细拖拽 |
| 列表详情 | 双击可快捷、单击入口 | Enter 激活明确入口 | Tap | 避免双击唯一入口 |
| 关闭浮层 | 点击关闭 / Escape | Escape、关闭按钮 | 关闭/返回/外点（视任务） | 未保存数据需保护 |

## Focus 与提示

- 每个可操作元素应具有清晰 Focus-visible；不要直接删除 outline 而不提供替代方案。
- 工具提示 Tooltip 不能只在 Hover 出现；必须满足键盘访问或以可见文字给出核心说明。
- 键盘快捷键需可发现，且与浏览器/系统快捷键不冲突；表单输入期间避免热键误触发。
- 拖拽排序提供非拖拽替代操作；多指或长按手势不承担唯一功能。

## 验收

相同任务分别仅用键盘、仅用触摸、鼠标验证；触屏笔记本使用混合方式复验焦点、尺寸与 hover 特性。
