# 替代关系

基于同主题记录的搜索结果，结合当前文档、Issue/PR 和代码核实决定范围。

- 完整替代：新记录链接 `supersedes`；旧记录允许修改时补 `superseded-by`，冻结记录则由新记录或已有导航表达关系。当前 owner 承接旧记录独有理由、备选方案、后果和必要验证后，再处理旧记录；删除另按项目规则与授权处理。
- 部分替代：两份记录都保留，写明各自仍有效的范围和当前所有者。
- 仅实现变化：更新当前事实 owner；仅在项目允许时更新原决策的实现说明，不为普通修订创建新决策。
- 决策反转：创建新记录说明新理由、旧取舍和迁移风险，不能把旧记录改写成相反决定。

归档条件按 [生命周期](lifecycle.md) 判断，文件操作按 [目录组织](organization.md) 处理。
