# 设计记录生命周期

先读取项目已有 ADR/设计生命周期；状态名、存储位置和冻结规则以项目为准。以下是无既有约定时的默认模型，通过路径或头部表达状态，不要求所有项目迁移。

- `proposed`：目标、方案、验收标准、风险和未决问题；可以描述未实现行为。
- `implemented`：已交付 Decision、实际 Consequences、测试和验证；当前子系统和包 README 必须同步。
- `rejected`：保存否决理由，只有仍能阻止有意义误用时才保留。
- `archived`：历史快照，不是当前事实来源；项目如有冻结规则，归档后不得修改正文。

默认模型中的状态移动不只是改名，还要同步正文、链接、当前事实和验证。项目采用不可变 ADR 时，通过后续记录或索引表达实现和替代状态，保留原始决定；不要把 `accepted` 等采纳状态当成实现证据。
