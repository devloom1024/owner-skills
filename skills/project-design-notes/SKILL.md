# 项目设计记录

设计记录保存代码、测试和当前文档无法表达的长期理由。它可以描述未来目标，但不能冒充当前运行行为；当前行为由源码、测试、生成器、subsystem 和包 README 共同证明。

审查请求保持只读；明确要求创建、更新或转换记录时直接执行。一个决定范围只有一个当前 owner，先更新同主题记录；只有产生新的长期取舍或决策反转时才新建记录。

本库以项目根下 `.agents/notes/` 为唯一活跃决策记录根，架构类记录承担 ADR 职责。涉及既有记录时核实实际 owner，不因位置不同自动重组目录或复制正文。

## 先读什么

- 根及记录实际路径的祖先 `AGENTS.md`；
- 当前 subsystem 和包 README；
- 查找、新建、移动或归档记录时读 [目录组织](references/organization.md)；
- 状态判断、交付或归档时读 [生命周期](references/lifecycle.md)，保留项目已有语义；
- 创建或改写记录时读 [记录格式](references/format.md)，从中选择适用模板；
- 交付收敛时读 [提案转换](references/transition.md)，涉及方案替代时读 [替代关系](references/supersession.md)。

## 工作流

1. 固定设计主题、读者、范围、非目标和当前实现状态。
2. 查找同主题记录和相关拒绝理由，先判断是否存在完整或部分替代关系。
3. 确有新决策时，在约定位置创建记录，按记录格式选择项目模板或默认模板。
4. 实现时逐项检查验收标准；如果方案、边界或取舍变化，更新该记录或创建明确替代记录，不让旧提案继续代表新决策。
5. 交付时按项目生命周期收敛记录并同步当前文档，写清实际偏差及代码、测试、PR 或新决策证据。
6. 否决、替代或归档时保留可追溯的理由与关系；文件操作按目录组织处理。

## 输出

报告状态含义、文件位置、替代关系、验收项、偏差、实际验证和未决问题。涉及移动或归档时补充源/目标路径、关联文件、引用处理及冻结限制；不擅自扩大范围、删除记录或重写冻结历史。
