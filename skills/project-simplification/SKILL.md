# 项目简化

简化候选必须说明删除或合并的对象、现有消费者、行为影响、替代方案和验证方式。

## 检查顺序

1. 搜索重复事实和多个所有者；
2. 查找重复状态、配置、适配层和接口；
3. 查找没有实际消费者的抽象；
4. 查找已被当前实现替代的设计记录；
5. 区分删除概念、移动所有权和压缩表达；
6. 检查简化是否改变公开行为、数据兼容性或失败保证；
7. 输出候选优先级、证据、风险、迁移步骤和验证。

## 边界

建议必须有源码、调用方、测试或文档证据。默认只读，不直接删除代码、文档、测试或目录。
