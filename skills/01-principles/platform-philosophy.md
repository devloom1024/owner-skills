# 平台设计原则

## 三个不同的维度（禁止混为一谈）

- **运行平台**：Web / Electron / PWA / 原生包装。影响系统菜单、权限、窗口和浏览器环境。
- **空间条件**：当前可用内容容器宽度、高度；决定可容纳几个栏位。
- **输入模式**：鼠标 / 键盘 / 触摸 / 手写笔 / 混合；决定命中区域和交互入口。

同一平板可横屏、接键盘；同一 Electron 窗口可能仅 420px 宽。因此“Desktop=宽屏、Mobile=窄屏”只能作为初步场景，不是设计判断公式。

## 共同体验，不同载体

| 保持一致 | 可以改变 |
|---|---|
| 页面目的、术语、信息分组、状态与数据含义 | 栏数、视觉密度、操作入口、导航容器 |
| 保存与删除的结果/验证规则 | Dialog/Sheet/全屏形式、是否提供键盘捷径 |
| 错误恢复、无障碍目标 | Hover/右键/长按作为辅助操作 |

## 决策准则

1. 布局首先由**容器是否放得下**决定，优先折叠次要面板。
2. 密度首先由**输入方式和偏好**决定，尤其确保触摸命中区域。
3. 关键功能的入口不因平台变得不可发现。
4. 交互方式遵循用户对设备的期待，但不盲目模拟系统控件。
