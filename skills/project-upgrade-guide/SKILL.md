# 项目升级指南

当变更影响外部消费者时，记录旧行为、新行为和可执行的迁移路径。

## 工作流

1. 阅读版本来源、发布规则、兼容性记录和变更 diff。
2. 判断变化是否影响外部用户、调用方、持久化数据或公开接口。
3. 固定版本、受影响对象、旧行为、新行为、迁移步骤、兼容期和失败处理。
4. 生成 `v<version>/<item>/guide.md` 形式的升级指南或更新现有指南。
5. 链接设计记录、实现、测试和验证命令。
6. 检查本地链接、版本名称和迁移步骤；未验证项必须明确写出。

## 输出结构

```text
影响范围
变化说明
迁移步骤
兼容性和限制
验证方式
```

默认只读规划。发布版本和迁移策略由项目自身的 AGENTS.md 与配置决定。
