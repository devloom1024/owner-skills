# 事实验证

当前事实必须有源码、测试、配置、生成器或已运行命令支持。

1. 找到声明对应的 canonical source；
2. 读取相关实现、调用方和测试；
3. 对文档中的命令、配置、默认值、错误和平台行为实际运行，或明确记录验证负责人；
4. 区分 `observed`、`test-backed`、`mechanical`、`review-only` 和 `unknown`；
5. 更新事实源后，同一变更更新派生文档和生成产物；
6. 生成文档先重新生成，再做 freshness、链接和内容检查；
7. 双语文档、类型等价、快照和文档预算按项目门禁验证。

未运行命令不能被写成“已验证”；命令失败或环境缺失要写入报告。
