# 指令层级

`AGENTS.md` 对所在目录及其后代目录生效。处理变更时，从根目录开始，依次读取变更路径上每一级祖先目录的指令文件，形成有效规则集合。`docs/AGENTS.md` 默认约束 `docs/` 子树，不因为代码或 `.agents/notes/` 引用了文档就自动扩大作用域；显式引用的规则按其声明范围使用。

## 审计有效集合

对代表性代码和文档路径记录：

```text
根 AGENTS.md
→ 子树 AGENTS.md
→ 包或应用 AGENTS.md
→ 目标文件所在目录规则
→ 路由到的事实所有者和验证入口
```

检查父子规则是否可以同时执行、引用路径和命令是否存在、局部规则是否增加真实边界，以及变更路径是否能找到文档所有者。

## Notes 与跨目录移动

对 `.agents/notes/implemented/<class>/<record>.md`，检查根、`.agents/`、`.agents/notes/`、生命周期及分类目录中实际存在的祖先规则。不存在的指令文件不需要补建；只有确有局部边界时才增加规则。

移动文件时读取源位置和目标位置的有效规则，核实冻结、状态转换、格式及验证差异。源目录的规则不自动随文件迁移，目标目录的规则也不授权破坏源文件的封存约束。无法同时满足时报告冲突，不通过改路径规避限制。

## 输出状态

已有指令文件可标记为 `retain`、`merge`、`split`、`move`、`archive` 或 `review-required`。合理的既有层级不因模板而重写。
