# 指令层级

`AGENTS.md` 对所在目录及其后代目录生效。处理变更时，从根目录开始，依次读取变更路径上每一级祖先目录的指令文件，形成有效规则集合。`docs/AGENTS.md` 约束文档编辑；代码路径通过路由读取相关文档，不因此继承文档目录局部指令。

## 审计有效集合

对代表性代码和文档路径记录：

```text
根 AGENTS.md
→ 子树 AGENTS.md
→ 包或应用 AGENTS.md
→ 目标文件所在目录规则
→ 路由到的事实所有者和验证入口
```

检查父子规则是否可以同时执行、引用路径和命令是否存在、局部规则是否增加真实边界，以及变更路径是否能找到文档所有者。

## 输出状态

已有指令文件可标记为 `retain`、`merge`、`split`、`move`、`archive` 或 `review-required`。合理的既有层级不因模板而重写。
