# 文档指令

## 文档职责

- `architecture.md`：系统地图；
- `subsystems/`：当前类型、语义和实现边界；
- `agent-notes/`：持久化设计理由和生命周期；
- `postmortem/`：事故因果链和预防；
- `standards/`：审查规则及证据；
- `guides/`：有序操作流程；
- `contracts/`：机器契约来源、生成器和语义所有者。

## 维护规则

一条事实一个所有者；索引只导航；当前文档不写未实现行为；提案交给设计记录；生成文档先更新源再重新生成。

## 变更同步

职责、接口、状态、失败、兼容性、配置、生成区域或用户流程变化时，更新所属文档，或在变更影响报告中记录 `not-needed` / `review-required` 及证据。

## 验证

修复链接和索引；运行项目定义的 doc-sync、类型等价、双语、预算、生成 freshness 和测试门禁；未运行项必须报告。
