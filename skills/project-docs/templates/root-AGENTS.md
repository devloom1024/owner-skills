# 根仓库指令

## 先阅读

- `docs/architecture.md`：跨子系统行为和系统地图；
- 最近的 `AGENTS.md`：局部代码、测试和生成规则；
- 所属 subsystem/package README：当前契约和验证；
- applicable standards/design notes：规范与持久化理由。

## 来源优先级

源码、机器可读契约、测试和生成器优先于当前事实文档；`proposed` 只说明目标；`implemented` 说明已交付决策；归档记录只作历史引用。

## 安全

保留用户修改；不手工编辑生成产物；变更前固定范围；报告未运行检查。

## 交接

说明 changed paths、canonical owners、设计偏差、不变量、命令和未验证风险。
