## 先阅读

- `docs/architecture.md`：跨子系统行为和系统地图；

## 决策记录

活跃决策记录统一在项目根下 `.agents/notes/`，架构类记录承担 ADR 职责。先读同主题记录，一个决定范围只有一个当前 owner；当前文档链接理由，不复制正文。

## 来源优先级

用源码、机器可读契约、测试和生成器核实运行现状；与规范或文档冲突时显式报告，不自动认定实现就是预期。设计记录按项目生命周期区分目标、已采纳决定和已交付行为；归档记录只作历史引用。

## 安全

保留用户修改；不手工编辑生成产物；变更前固定范围；报告未运行检查。遵循源/目标路径规则，不因移动或修链接改写冻结历史。
