# 项目测试可靠性

检查测试是否真实证明行为，以及测试之间是否隔离。

## 重点维度

- CI worker 和测试拓扑；
- 端口、临时目录、HOME、环境变量和凭据；
- 进程、线程、goroutine、任务和监听器的所有权；
- 时钟、超时、轮询和同步信号；
- 跨平台路径、权限和运行时差异；
- 测试结束前的停止、等待和清理；
- 回归测试在修复前是否真实失败；
- 失败是否可复现、可定位且不依赖顺序。

## 诊断规则

优先修复资源所有权和同步缺陷。不要用固定 sleep、增加重试次数、隐藏失败或全局串行化来掩盖问题。报告运行拓扑、证据、最小复现和未验证环境。
