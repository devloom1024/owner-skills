# Overlays — Mobile

> 先遵守 [Shared Overlays](overview.md)。

## 容器策略

- 触摸操作选择/少量选项可采用 Drawer / Bottom Sheet；全屏内容、长表单、多步骤确认首选独立页面。
- Bottom Sheet 的拖拽把手只是辅助；必须有明确标题、关闭或完成按钮，不能只靠下滑关闭。
- 短危险确认首选 AlertDialog；只有在动作列表语义明确且不会因误触触发时，才使用 Drawer 中的确认入口。
- 弹层的动作区、滚动区必须考虑底部 safe area 与软件键盘。

## Interaction

- 明确系统返回、下滑、点击遮罩、关闭按钮的行为一致性；有未保存内容时要阻止静默关闭或保存草稿。
- Sheet 高度可以根据内容和当前可用空间改变，但操作按钮始终可触达。
- 点击 More 按钮打开动作列表，保证每个动作触摸范围充分，不把唯一操作放长按手势里。
- 弹层关闭后恢复原页面位置和被操作对象的上下文；若对象已删除则跳到合理位置并反馈。

## Exceptions

手机横屏或小窗口软键盘占据较大空间时，即使是短表单也可以从 Sheet 改用完整页面；不属于不一致。

## 验收

320/390px、键盘展开/收起、iOS/Android 侧安全区、VoiceOver/TalkBack 对应 Web 可达性、返回与未保存数据。
