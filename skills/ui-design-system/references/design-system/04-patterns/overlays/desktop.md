# Overlays — 桌面端

> 先遵守 [Shared Overlays](overview.md)。

## 容器策略

- DropdownMenu/Popover 锚定触发控件，避免脱离对象造成位置感丢失；长菜单必要时滚动。
- 短期创建/编辑与确认优先 Dialog，保持适度宽度；大段文档或多步骤任务转为完整页面。
- 工具栏筛选可用 Popover；重要且高频的筛选不应只能通过隐藏子菜单访问。
- 复杂右侧 Inspector 属于页面布局，不应该被当作一直悬浮的 Dialog。

## Interaction / 交互

- 打开后管理焦点与屏幕阅读器语义；Escape 默认关闭可取消的最顶层弹层，关闭后焦点回触发控件。
- 点击外部关闭非模态菜单通常合理；存在未保存表单时不可静默丢失数据。
- Enter/Space 激活、方向键菜单导航按基础组件语义；不自行重写 shadcn 的低级可访问性机制。
- 危险操作显示动词及对象范围，不默认聚焦最危险按钮以避免快速回车误触。

## 视觉规则

使用 `radius.overlay=16px` 的统一浮层语义；表面、边框、阴影保持一个层次标准，不在不同业务对话框之间改变样式。

## 验收

鼠标、键盘、屏幕阅读器、100%/200% 字号、窗口缩到 500px、层内错误与焦点恢复。
