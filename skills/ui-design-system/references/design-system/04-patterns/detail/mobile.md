# Detail — 移动端

> 先遵守 [Shared Detail](overview.md)。

## 布局

- 默认单对象的全屏层级页面，有清晰返回、对象标题及主状态；正文按内容优先级分组纵向滚动。
- 将次要元数据折叠到详情小节或单独的“信息”页，但不能隐藏安全/错误等关键状态。
- 主操作数量少时可置顶栏或合理的底部动作区；固定底部操作必须处理安全区和软键盘。
- 仅在业务确实需要对照/检查时才引入移动二级页；不要将桌面 Inspector 无脑平移成右侧狭窄面板。
- 大量字段用可读标签-值垂直结构，避免在 320px 宽时硬塞两列字段。

## Interaction / 交互

- 系统返回、可见返回按钮与页面内部返回路径语义一致；从通知深链进入也能找到上级集合。
- 编辑打开专门表单页或全屏编辑模式；保存/取消策略遵循 Form Pattern。
- 更多对象操作通过可见菜单；滑动切换对象如存在，必须有显示当前对象与替代导航。
- 复杂文本、附件预览可进入沉浸式子页，退出后保持详情阅读位置。

## 验收

390/320px、字体放大、异步更新、已删除对象、软键盘、底部操作区及深链打开后返回。
