# Settings — 桌面端

> 先遵守 [Shared Settings](overview.md)，本文件仅定义桌面侧的布局与交互。

## 结构 & Layout

- **优先布局**：左侧类别 Sidebar + 右侧单列设置内容；类别约 200–260px 是起点，实际按可用空间和最长分类名调整。
- 设置主内容 `max-width:720px`，避免横向拉伸至显示器边缘；容器左右依 Page Shell 留白。
- 页面标题位于设置内容顶部；分组标题、行、说明保持一条对齐轴。
- 分组通常无需每组都放大卡片；可选背景分组或分隔线，选一种并全局一致。
- 在窗口不足容纳侧栏及主列时，先缩窄侧栏、再折叠为 Rail/抽屉/入口页；**不因为窗口窄就强制加手机底栏**。

## Interaction / 交互

- 支持键盘 Tab / Space 切换开关及下拉；焦点顺序按导航→标题→表单顺序。
- 左侧类别选中状态持续可见，URL/路由（如适用）可以分享当前类别。
- Hover 增加反馈但不能隐藏唯一编辑入口；鼠标点击行内值或可见控件进入具体设置。
- 高风险操作不放在普通设置行中间，可置于账号/高级分组底部。
- 切换类别时，是否恢复滚动位置必须有一致策略；默认先滚至新类别标题，返回则恢复已浏览位置。

## 状态与调整

- 保存中某一行呈行内 pending，不锁住整个设置页；全局影响设置可声明等待范围。
- 导航宽度 200px 已无法容纳时，不压缩正文为窄于可读宽的列；根据 [Responsive](../../05-platforms/responsive.md) 折叠次级区域。

## Do / Don't / 应该与不应该

✅ 右侧内容宽度受控、分组稳定、键盘可达。  
❌ 在 1440px 屏上将单行标签和 Switch 相隔超过 1000px。  
❌ 隐藏核心选项到仅 Hover 出现的“编辑”图标里。

## 验收

1440px/1024px/420px 桌面窗口，鼠标+键盘；验证分类展开/折叠、标签过长、滚动与焦点恢复。
