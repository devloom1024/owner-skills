# Settings — 移动端

> 先遵守 [Shared Settings](overview.md)，本文件规定有限空间/触摸呈现。

## 结构 & Layout

- **优先布局**：设置类别入口列表 → 选中类别的二级设置页（标题与 Back）；若设置项少，可直接在单一页面分组，不强制多一级。
- 单列内容，左右 16px 安全内容边距 + safe-area；常规设置行最小 56px，触摸目标推荐 ≥44px。
- 简短开关可在类别页直接展示，但不要混用“点击整行跳页”和“点击开关即时切换”而产生误触；两个动作分区明确。
- 多选或长描述设置优先二级页；Inline Slider 或选项过多不应在 390px 宽行内挤压标签。
- 底部导航仅在应用整体 IA 需要时存在；Settings 二级页通常保留明确返回机制。

## 交互

- Tap 开启设置、进入 Value Row；Swipe/Long Press 不能是唯一入口。
- 切换到二级选择页返回时恢复类别页滚动位置；值改变后在来源页即时反映。
- 打开键盘时确保文本框、保存动作与错误信息可见；考虑软键盘对底部固定区影响。
- 权限/系统设置跳转应明确说明将离开当前应用；失败/拒绝需要行内反馈。
- Danger 操作使用明确文案和确认方式，避免底部一触误删。

## 例外

少量设置可单页显示；平板触摸宽屏可采用两栏 Settings，**但仍维持 touch 控件尺寸**。

## 应该 / 不应该

✅ 类别/详情导航清楚，行高统一。  
❌ 复制桌面左侧 240px 常驻 Sidebar 把内容压到 150px。  
❌ 仅靠右滑打开高级设置，页面上没有可见入口。

## 验收

390px/320px 竖屏、820px 平板触控；测试返回、屏幕旋转、软键盘、系统字号放大、深色模式和安全区。
