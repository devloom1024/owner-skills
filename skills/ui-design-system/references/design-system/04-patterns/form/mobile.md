# Form — Mobile

> 先遵守 [Shared Form](overview.md)。

## 布局

- **默认单列字段**，顺序与共享 Pattern 相同；各输入控件默认至少 44px 高，触摸目标充分。
- 左右采用 16px 内容边距 + safe area；多行文本自增长或明确可滚动。
- 主要操作可在表单底部，如采用 sticky footer，必须为内容留出空间，打开软键盘时仍能看到当前字段/错误及提交动作。
- 复杂表单可以分步骤；步骤之间显示进度、允许返回编辑、不意外丢失已填信息。
- 输入类型匹配移动键盘（邮箱、数字、电话等），但允许复制/粘贴与密码管理器。

## Interaction

- 使用原生系统键盘的 Done/Next 意义，最后字段的键盘完成按钮不应默认绕过校验。
- 错误定位优先滚动到首个相关字段并展示可理解文案；避免 Toast 唯一提示。
- 返回按钮触发明确的未保存状态处理；包括系统返回/手势返回。
- Sheet 内复杂表单可能与软键盘、滚动冲突，优先转为独立页面。

## Do / Don't

✅ 字段充足高度，完成动作始终可达。  
❌ 手机表单照搬桌面 2–3 列，标签和值互相挤压。  
❌ 底部保存按钮被软键盘遮住，用户必须关闭键盘才能看到错误。

## 验收

320/390/430px、软件键盘/自动填充、长表单、回退、弱网失败、字体放大和 iOS/Android 安全区差异。
