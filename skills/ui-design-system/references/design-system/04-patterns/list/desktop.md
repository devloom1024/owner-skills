# List — Desktop

> 先遵守 [Shared List](overview.md)。

## 布局

- **信息密度较高时优先 Table**：列名、对齐、可排序头、对象主列固定识别优先；不为视觉时髦把表格改为几十张大卡片。
- 列宽优先保障主标识；数值右对齐、日期/状态遵循一致样式；过多列允许列显隐/横向滚动，但不能默默裁切关键字段。
- 搜索/过滤与排序放在结果上方工具栏；批量模式清楚提示已选数量。
- Compact 默认列表行高约 44–52px，可视内容决定增长；行内动作应有不依赖 hover 的替代入口。
- 数据表可占满主容器，但不要超过主内容时隐藏操作列而不提供替代。

## Interaction

- 标题或明确链接打开详情；Checkbox/行操作分别有独立命中区，避免点击复选框误开详情。
- 鼠标 Hover 高亮可用于扫视，不应成为唯一可访问的更多动作入口。
- 使用键盘在筛选、选择与行操作之间移动；快捷键可提升效率，但不得替代可见操作。
- 支持表格列排序（升/降/不排序状态清晰）；键盘与屏幕阅读器可识别状态。
- 可选择 List–Detail 双栏，但侧边详情是辅助视图，关闭后应保持列表筛选和位置。

## 响应式降级

从宽到窄：隐藏低优先列 → 将次要动作收纳到明确菜单 → 转为摘要列表或卡片；不要只把整张桌面表压成 5 个 40px 列。

## 验收

1440/1024/600/420px，测试长标题、20列、0/1000条、键盘选择、排序与返回状态、右键非唯一入口。
