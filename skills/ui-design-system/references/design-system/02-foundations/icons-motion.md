# Icons & Motion — 图标、反馈和动画

## 图标

- 优先单一图标语言（例如 Lucide 风格），笔画、光学尺寸和图标颜色一致。
- 常用图标视觉大小：Desktop 16–20px，Touch 20–24px；**视觉尺寸不等于触摸目标尺寸**，小图标按钮仍需足够点击区域。
- 危险、成功、错误不能只靠图标符号或颜色表达，必须附加文字/可访问名称。
- 图标按钮必须提供可访问名称；图标在同一位置表达同一含义。

## 动画（建议等级）

| Token | 时长 | 场景 |
|---|---:|---|
| `motion.fast` | 120ms | 轻微状态反馈、hover |
| `motion.normal` | 200ms | 页面区域显隐、普通弹层 |
| `motion.slow` | 280ms | 需要强调空间连续性的过渡 |

优先使用透明度/transform 而非大量触发布局重排的动画；减少动画偏好（`prefers-reduced-motion`）下关闭非必要移动/缩放。动画不能阻塞提交、导航或错误恢复。

## Do / Don't

✅ 页面进入和退出保持同一方向与层级。  
❌ 一个页面 150ms、另一个 600ms 的随意弹窗动效。  
✅ 用骨架屏表达加载且防止内容跳变。  
❌ 只用无限旋转动画告诉用户“正在处理”而无状态文案。

## 验收

键盘与鼠标触发的状态反馈一致，低性能设备可接受，减少动画模式无明显信息丢失。
