# 间距与布局 — 4px 网格与容器

## 间距刻度

| Token | 值 | 推荐用途 |
|---|---:|---|
| `space.1` | 4px | 图标与数字、极紧密内容 |
| `space.2` | 8px | 图标与文字、紧凑项间距 |
| `space.3` | 12px | 小型容器内部 |
| `space.4` | 16px | 标准控件与移动端页面边距 |
| `space.5` | 20px | 舒适型控件分组 |
| `space.6` | 24px | 标准分组、桌面页面留白 |
| `space.8` | 32px | 主区块间距与宽屏边距 |
| `space.10` | 40px | 大型章节区隔 |
| `space.12` | 48px | 大段内容分区 |
| `space.16` | 64px | 特殊空白区域（需说明） |

## 布局权责

- **App Shell**：负责全局导航、系统栏和主内容剩余区域。
- **Page Container**：负责主要内边距、最大宽度和页面级滚动容器。
- **Pattern**：负责区域之间的关系，如 SettingSection、Table / Filters / Detail Pane。
- **Component**：仅负责自身尺寸/内部 padding，不反向给整个页面加外边距。

同一级留白只能由一层负责，禁止 Shell + Page + Card 重复叠加 padding。

## 推荐容器

| 任务 | 推荐策略 |
|---|---|
| 设置页主列 | max-width: 720px，可居中或对齐内容区起点 |
| 常规表单 | max-width: 640px |
| 长文档/阅读区 | max-width: 720px，必要时独立目录 |
| 数据表 / 管理后台 | 充分利用可用宽度，结合水平滚动和列管理 |
| 移动单列 | 16px 左右安全内容边距（叠加系统安全区） |

安全区域使用 `max(页面内边距, env(safe-area-inset-*))` 合并，避免在有刘海/系统手势区域的设备上重复或不足留白；具体 CSS/API 语法按目标平台实现。

## 应该 / 不应该

✅ 使用 16/24/32px 一致的分组韵律。  
❌ 同一列表 item 一会 14px、一会 18px，靠感官补偿。  
✅ 内容少时保持结构稳定，利用合理对齐而不是强行拉伸卡片。  
❌ 用固定页面高度、绝对定位隐藏超长文字或系统键盘。

## 验收

缩窄与放大容器，检查多列顺序、重复 padding、横向溢出、长标题折行和右侧操作区；至少测试 320/390/768/1024/1440 CSS px 典型视口（布局设计仍以实际容器为准）。
