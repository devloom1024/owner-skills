# 桌面端 — 桌面交互的横向能力

## 主要能力

- 支持持续性侧栏/导航 Rail、工具栏、键盘与指针、多窗口；仅在空间足够时展示额外详情面板。
- 可使用紧凑密度，但视认性/Focus/命中区不可过度缩减。
- Hover、右键、快捷键是效率增强，而不是完成关键任务的唯一途径。
- 对应表格提供列标题、排序与键盘访问；行级动作不要干扰文本选择。

## 布局规范

- 页面主区域默认左右 24px（宽屏 32px），设置/表单遵守最大阅读宽度。
- Sidebar 常驻时显示当前位置；宽度不足时可折叠为 Rail 或抽屉，但主内容需要保留。
- Inspector 作为次要栏，优先可关闭、可恢复；不得将核心详情仅放在可隐藏区域。
- 操作按钮优先位于页面标题旁、工具栏或对象行级操作区，勿重复多处同一危险入口。

## 系统与输入

- 尊重系统的关闭、最小化、菜单和快捷键习惯；Electron 自定义标题栏要考虑拖拽/窗口控制区域。
- 删除、保存、导航与模态关闭等快捷键需明确语义，不能覆盖浏览器/OS 关键快捷键。
- Escape 先关闭最上层可关闭弹层，再退出局部选择；不要意外丢弃内容。

## 典型禁例

❌ 把重要操作只放到 Hover 按钮。  
❌ 窗口缩到 500px 时直接空白，而不是折叠检查器。  
❌ 按 Enter 激活会意外提交危险任务，没有清晰焦点提示。
