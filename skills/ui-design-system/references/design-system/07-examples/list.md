# List — 结构示例与验证

规范：[共享](../04-patterns/list/overview.md) · [桌面](../04-patterns/list/desktop.md) · [移动](../04-patterns/list/mobile.md)

## Desktop

```text
项目列表                                  [+ 新建项目]
[搜索项目........] [状态筛选 ▾] [排序 ▾]    共 128 项
┌──────┬──────────────────┬────────┬─────────┬─────────┐
│ 选中 │ 项目名称         │ 状态   │ 更新时间│ 更多操作│
├──────┼──────────────────┼────────┼─────────┼─────────┤
│ □    │ Project Alpha    │ 进行中 │ 昨天    │ ...     │
│ □    │ Project Beta     │ 已归档 │ 今天    │ ...     │
└──────┴──────────────────┴────────┴─────────┴─────────┘
```

## Mobile

```text
项目                                 [+]
[搜索项目.........................]
[状态: 进行中 ×] [筛选 ▾] [排序 ▾]
┌─────────────────────────────────┐
│ Project Alpha              ... │
│ 进行中 · 昨天                   │
├─────────────────────────────────┤
│ Project Beta               ... │
│ 已归档 · 今天                   │
└─────────────────────────────────┘
```

## 规则说明

- 两端共用项目身份、状态和时间字段，移动端不删除重要对象识别信息。
- 搜索/筛选/排序状态可恢复；移动端将复杂筛选放入可见入口的 Sheet。
- 多选模式显式提示数量；更多操作不是纯 Hover。

## Do / Don't

✅ Mobile 摘要优先、详情承接次级字段。  
❌ Mobile 把原桌面所有列缩小到每列 30px，也不提供横向滚动线索。

## 验收

空列表、无搜索结果、超过 1000 条、进入详情再返回、多选删除失败和结果更新。
