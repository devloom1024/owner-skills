# Settings — 结构示例与验证

规范：[共享](../04-patterns/settings/overview.md) · [桌面](../04-patterns/settings/desktop.md) · [移动](../04-patterns/settings/mobile.md)

## 桌面端 / 宽内容区

```text
┌──── 全局应用导航 ────┬──────────────────────────────────────┐
│  工作区 / 项目 / ... │ 设置  > 外观                          │
│                     │                                      │
│  设置分类           │  外观                                │
│  ├─ 外观（选中）    │  ──────────────────────────────────  │
│  ├─ 通知            │  主题模式    跟随系统   [打开选择]    │
│  ├─ 隐私            │  桌面通知    [Switch]                │
│  └─ 账户            │  字体大小    默认       [打开选择]    │
│                     │  （主内容 max 720px）                 │
└─────────────────────┴──────────────────────────────────────┘
```

## 移动端 / 触摸单列

```text
┌──────────────────────────┐     ┌──────────────────────────┐
│ 设置                     │     │ ‹ 设置       外观          │
│                          │     │                          │
│  外观               ›    │     │  主题模式   跟随系统  ›   │
│  通知               ›    │  →  │  桌面通知   [Switch]      │
│  隐私               ›    │     │  字体大小   默认      ›   │
│  账户               ›    │     │                          │
└──────────────────────────┘     └──────────────────────────┘
```

## 规则说明

- 桌面与移动端分类名称、设置含义、值保持相同，移动端只是将分类页与详情页分层。
- 桌面端 右侧内容不随着大屏无限变宽；移动端 行高 ≥56px，操作目标推荐 ≥44px。
- 如果只有 5–8 个简单设置项，移动端 可以直接单页分组，不强制二级分类。

## 应该 / 不应该

✅ 主题、通知在所有项目使用同一行类型与信息层级。  
❌ 同一设置“通知”在 A 项目是 Switch，B 项目点击行直接切换且看不到当前值（除非差异有记录）。

## 验收场景

切换主题失败后的恢复；长文字/中文混排；触摸开关不误触整行进入详情；系统返回恢复列表位置。
