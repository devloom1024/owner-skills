# Form — 结构示例与验证

规范：[共享](../04-patterns/form/overview.md) · [桌面](../04-patterns/form/desktop.md) · [移动](../04-patterns/form/mobile.md)

## Desktop

```text
编辑个人信息
姓名 *
[_______________________________]
邮箱 *
[_______________________________]
请输入有效邮箱地址（如发生错误在该字段下显示）

[取消]               [保存更改]
```

## Mobile

```text
‹ 编辑个人信息

姓名 *
[________________________]

邮箱 *
[________________________]
错误：请输入有效邮箱地址

（内容可滚动、键盘展开不遮挡字段）
────────────────────────
[保存更改]  （固定时考虑底部安全区）
```

## 规则说明

- 每个字段 Label 持续可见，错误信息在字段附近；两端校验规则完全相同。
- 移动单列，输入法类型适配；桌面键盘 Tab 可操作。
- 离开有未保存变更时统一处理；网络失败不清空输入。

## Do / Don't

✅ 字段错误可恢复，保存与取消一致。  
❌ 保存失败只显示 Toast 然后清空表单；手机键盘挡住提交按钮。

## 验收

提交成功/失败、未保存返回、自动填充、长文案/字号放大、键盘操作和弱网。
