# Detail — 结构示例与验证

规范：[共享](../04-patterns/detail/overview.md) · [桌面](../04-patterns/detail/desktop.md) · [移动](../04-patterns/detail/mobile.md)

## 桌面端

```text
‹ 项目列表   Project Alpha       [编辑] [更多 ▾]
┌───────────────────────────┬────────────────────┐
│ 摘要 / 状态 / 关键内容    │ 可选 Inspector     │
│                           │ 成员 / 标签 / 关系 │
│ 活动 / 附件 / 相关记录    │ （可以折叠）        │
└───────────────────────────┴────────────────────┘
```

## 移动端

```text
‹ 项目列表             [...]
Project Alpha
状态：进行中
────────────────────────
摘要内容
────────────────────────
活动记录
────────────────────────
附件 / 关联对象
[编辑]（可置顶或位于安全底部区域）
```

## 规则说明

- Inspector 是次要区，移动端可变成独立小节；主状态不能因为折叠消失。
- 编辑与返回在两端含义相同；从外部深链打开也应提供上级路径。
- 固定底部按钮应留 Safe Area，不遮挡内容。

## 应该 / 不应该

✅ 对象身份与状态在各平台都能迅速辨认。  
❌ 桌面主操作可见，移动端把它隐藏到连续三级菜单而无理由。

## 验收

对象被删/失权、网络中断、过长名称、从通知进入、从编辑页返回保留位置。
