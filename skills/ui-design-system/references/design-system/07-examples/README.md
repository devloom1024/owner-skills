# Examples — 视觉结构与正反例

> 本目录只有 **Markdown 结构示例、选择建议与验收场景**；不提供 TSX/CSS 组件源码，也不假装等同于像素级设计稿。目标是帮助人与 AI 理解规范如何组合。

## 如何用

1. 先读对应 `04-patterns/<name>/overview.md`，再读两个平台文件。
2. 使用本目录的结构图确认主次关系，而不是逐字符复制 ASCII 边界。
3. 完成实际设计后结合 [UI 验收清单](../06-governance/review-checklist.md) 交叉检查。

结构图中的文字和按钮排列仅说明信息关系；视觉尺寸以 Token 规范为准。底部导航并非移动端强制项，只有 IA 适合才使用。
