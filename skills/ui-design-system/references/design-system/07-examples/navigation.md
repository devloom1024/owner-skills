# Navigation — 结构示例与验证

规范：[共享](../04-patterns/navigation/overview.md) · [桌面](../04-patterns/navigation/desktop.md) · [移动](../04-patterns/navigation/mobile.md)

## 共享信息架构示例

```text
一级：首页 / 项目 / 活动 / 设置
项目（一级） → 项目列表 → 单个项目详情（深层）
设置（一级） → 设置分类 → 外观设置（深层）
```

## Desktop / 桌面端

```text
┌──── Sidebar ────┬─────────────────────────────┐
│ 首页            │ 页面标题                    │
│ 项目（当前）    │ 项目列表 / 主内容           │
│ 活动            │                             │
│ 设置            │                             │
└─────────────────┴─────────────────────────────┘
```

## Mobile / 移动端（仅顶层目标适合 Bottom Tabs 时）

```text
┌─────────────────────────────┐
│ 项目列表                     │
│ 主内容                       │
│                              │
├─────────────────────────────┤
│ 首页    项目    活动   设置   │
└─────────────────────────────┘
```

进入“项目详情”时使用 `‹ 项目列表` 返回；不让用户猜测需要点击“项目 Tab”才能回到之前的位置。

## Do / Don't / 应该与不应该

✅ 顶层导航标签、当前页语义一致，深层返回稳定。  
❌ 桌面仅 420px 宽就强制把整个导航改成 iOS 风格底栏。

## 验收

窗口缩放、深链、返回、键盘操作、权限限制、当前选中态和未保存草稿。
