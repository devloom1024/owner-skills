# Actions & Inputs — 操作与输入组件

## 按钮优先级

| 类型 | 使用条件 | 规则 |
|---|---|---|
| Primary | 页面当前主要目标 | 一个操作区域原则上只有一个主要 CTA |
| Secondary / Outline | 辅助可替代操作 | 不与主要操作抢夺视觉层级 |
| Ghost | 工具栏、低强调动作 | 仍需完整 Focus 与触摸范围 |
| Destructive | 危险、不可逆或高风险操作 | 清晰动词、确认/撤销策略适合风险 |

## 尺寸与位置

- Compact 默认 Button/Input 高 36px，重要主操作可 40px；Comfortable 44px，重要主操作可 48px。
- 不应把 16px 图标视为 16px 的点击目标。
- 输入标签必须持续可见；placeholder 不替代 Label。
- 文本表单：标签 → 输入 → 辅助说明/错误，错误紧邻对应字段。
- 数字输入注明单位、范围与格式；密码/敏感字段提供必要可见性控制和防误操作。

## 选择控件

- 即时生效开关：Switch + 可发现的状态标签；涉及重大后果时改为显式确认流程。
- 多选或跟随表单提交：Checkbox；互斥选项：Radio，候选项很多时 Select。
- Segmented 只用于少量同级互斥选项（一般 2–4），长标签不要勉强压缩。
- 列表搜索与过滤要说明作用范围，并提供清除入口。

## Do / Don't / 应该与不应该

✅ “保存更改”高强调，“取消”低强调；禁用保存要有可理解原因。  
❌ 删除、取消、保存三个按钮全用同一种高强调样式。  
✅ 编辑表单中错误保留用户已输入内容。  
❌ 输入不合法立即清空整张表单。

## 验收

连续 Tab 能按阅读顺序达到全部控件；Enter/Space 语义正确；手指操作无误触；文案准确描述结果。
