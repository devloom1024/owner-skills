# List — Shared Pattern

## 1. Purpose

用于浏览、查找、筛选、排序及管理**同类型对象集合**，如任务、文件、会话、客户、日志或项目。不是纯展示多个无关系营销卡片。

## 2. Anatomy

1. **Context & Title**：列表标题、总量/范围、主要新增动作。
2. **Search / Filter / Sort**：搜索范围明确，可显示活动筛选条件和清除入口。
3. **Result Container**：表格、列表行或摘要卡片，同一对象有稳定识别信息。
4. **Selection & Bulk Actions**：多选状态、选中数量、批量行为（只有需要时启用）。
5. **Pagination / Load More**：针对结果规模选择分页/增量加载，避免数据和浏览位置丢失。
6. **Result States**：Loading、Empty（无数据）、No Results（被过滤为零）、Error、Offline。

## 3. 一致的信息模型

- 定义对象的**主识别字段**、次要元数据、状态、关键操作；Desktop/Mobile 一定使用同样的数据语义。
- 排序/过滤状态保持一致，明确其范围（当前列表或全局）；尽量在 URL/状态容器中保存，支持返回。
- “打开详情”和“选择此对象”必须是可区别的动作；可多选时禁止点击含义模糊。
- 数据量大时使用分页/虚拟化，但选中状态不能因回收可视区域而丢失；跨页全选须说明范围。
- 列表加载仅替换结果区域，不应重置搜索栏与整个页面骨架。

## 4. 状态规则

| 状态 | 推荐体验 |
|---|---|
| First Load | 表头/搜索区保持稳定，结果骨架/进度反馈 |
| Empty Dataset | 告知暂无对象 + 合理创建/导入入口 |
| No Results | 显示过滤条件并提供清除筛选 |
| Error | 说明失败、保留条件、可重试 |
| Partial / Updating | 行内同步状态，不导致整页闪烁 |
| Selection | 显示数量、可取消、危险批量动作确认范围 |

## 5. Do / Don't

✅ 同一种对象的列表使用同一字段优先级和相同状态样式。  
❌ 窗口窄时直接移除唯一的对象身份信息。  
✅ 搜索、排序和过滤可清除、可返回。  
❌ 每次打开详情返回都重置过滤并跳到列表顶部。
