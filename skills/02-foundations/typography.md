# Typography — 字体与信息层级

## 字体栈

中文 UI 优先系统无衬线字体及对应系统 fallback；代码、路径、数字可使用等宽字体，但不应用等宽字体显示长篇 UI 文本。字体方案由项目品牌配置，不以固定商业字体为前提。

## 字体语义表（字号 / 行高 / 字重）

| 语义 | Desktop compact | Mobile/Touch comfortable | 场景 |
|---|---|---|---|
| Page Title | 24 / 32 / 600 | 24 / 32 / 600 | 页面唯一一级标题 |
| Section Title | 16 / 24 / 600 | 17 / 26 / 600 | 设置分组、卡片章节 |
| Body | 14 / 22 / 400 | 16 / 24 / 400 | 标准内容 |
| Label | 14 / 20 / 500 | 16 / 24 / 500 | 输入项、按钮、行名称 |
| Caption | 12 / 18 / 400 | 14 / 20 / 400 | 辅助描述、时间、提示 |
| Micro | 11 / 16 / 500 | 12 / 18 / 500 | 小徽标，仅非关键信息 |

**注**：单位为 CSS px。移动端触控模式是默认建议，不应禁止动态字号/浏览器缩放；非 Web 端按平台单位转换与验证。

## 规则

1. 页面原则上只出现一个语义 Page Title；次级标题使用 Section Title，避免多层随机字号。
2. 主要内容推荐 line-height 为字号的约 1.4–1.6 倍；不可通过固定高度裁切长文案。
3. 不通过纯颜色或纯字重区分错误与正常状态；应同时提供文本/图标。
4. 中文、英文、数字混排与长标题检查换行；支持 200% 字体缩放、不遮挡必要操作。
5. 除 Logo 或独立展示外，避免全部大写英文作为主要可读标签。
6. 常用权重以 400 / 500 / 600 为主，标题例外需品牌理由。

## Do / Don't

- ✅ 两个设置区域统一 Section Title；描述始终 Caption。
- ❌ 某个页面用 15px 正文另一个用 13px，靠“看着差不多”判断。
- ✅ 窗口缩窄时允许标题换行，不降低到不可读字号。
- ❌ 为让一行放下，把主标题固定为 12px。

## 验收

逐页检查 Page Title、Section Title、Body、Label、Caption；抽取一个中文最长内容、一个英文最长内容以及 200% 缩放条件进行排版回归。
